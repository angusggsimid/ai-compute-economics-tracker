# FIX_LOG 2026-11-03

## P0 + P1：GPU 供给全景与证据链

### P0 数据层

- 新增 `html_dashboard/gpu_landscape.py`，从现有 `neocloud_provider_price_history.json` 生成 11 张关键卡的日频供给面板：
  - H100 80GB、H200 141GB、B200 192GB、B300 288GB、A100 80GB、L40S 48GB、RTX PRO 6000 96GB、RTX 4090 24GB、RTX 5090 32GB、MI300X 192GB、GH200 96GB。
  - 每张卡拆 6 个 market：正规 on-demand、Spot、Reserved、Community、Marketplace floor、Serverless。
- 主 on-demand 收紧为 `on-demand + secure`，剔除 community/spot/reserved/marketplace/serverless；`_gpu_from_neocloud` 与 `thesis_engine.RENTAL_KINDS` 同步收紧，Supply 时钟与页面不再各用一套口径。
- 每家 provider 先取当日中位，再跨 provider 取中位；P25/P75 少于 4 家留空；state 为 live / unconfirmed / stopped，相对数据最新日计算。
- 新增 `dataAgeDays` / `dataFreshness`：数据截至日与构建日分开；超过 2 天显示“数据滞后”，不再把 10/29 的快照说成当天。

### P1 证据链

- 每张卡新增周度 `chain-linked base-100`：每周 provider 一次；≥4 家才发布；只取两周都在的 provider 做几何链接；当前周 provisional，收盘后 final。
- 每周 receipt 包含 included 报价（provider、价格、日期、source URL）和 excludedQuoteRowsByMarket（spot/community/reserved/marketplace/serverless 的行数）。
- 新增公开数据：
  - `public/data/prices.json`：最新 provider × card × market 报价。
  - `public/data/gpus.json`：11 卡 summary + 分市场最新。
  - `public/data/providers.json`：provider 覆盖与最低报价。
  - `public/data/price-index.json`：周度指数 + receipts。
  - `public/data/changelog.json`：周度指数变化。
  - `public/data/manifest.json`：口径、版本、文件清单、数据年龄。
- 页面“下载本周回执 CSV”从 `price-index.json` 生成；H100 2026-W44 回执 31 行（25 个 included + 5 个 excluded 市场汇总）。
- 页面内新增“口径、状态与证据”折叠区；数据文件链接可直接下载。
